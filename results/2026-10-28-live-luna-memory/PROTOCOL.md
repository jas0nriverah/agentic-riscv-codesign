# Frozen live subagent development pilot

Two fresh GPT-6 Luna subagents, explicitly configured model alias `gpt-6-luna`,
reasoning effort medium, no inherited conversation. One episode each on consumed
SHA256, seed 0, +64 LUT4, 12 MHz, three charged archived measurement attempts,
ten decision turns maximum. Compare no retrieval against local hybrid historical
memory. Identical historical information, tools and numeric predictors. Hybrid
adds a deterministic top-three ordering of already available history. Neither
agent receives unqueried target outcomes or the other agent's decisions.

Root relays each raw structured action unchanged to the charged host. Agents may
only read their explicitly assigned public request file and emit one JSON action;
no workspace searches, network, other files, or communications with other agents.
This is an instruction-enforced boundary, not a sandbox. Record any violation.
No failed trajectory replacement, prompt tuning, candidate-ID correction or retry.
Tokens, exact deployment version and model-only latency are unavailable. Host
wall time includes orchestration and waiting. These are real LLM decisions on
archived hardware evidence, not live synthesis or an untouched-workload test.

Primary endpoint: best paid verified feasible speedup at B3. Preserve B1/B2
prefixes, selected final outcome, charged cost, malformed calls, and comparison
against archived same-seed frequency, merit, random, ranking, latency/cost and
non-agent GP. One episode per arm cannot establish causal or statistical benefit.
No superiority claim from a tie or one favorable trajectory. Score only after
both agents finish. Source commit precedes first model request.
