# V11b: recover the reserved program-transfer inputs

This stage preserves the six original programs and their exact original O2 binaries. It prepares one new trace attempt for AMMUNITION and PM, and reuses the four completed V11 outcomes byte-for-byte. No model fitting, features, predictions or target labels are released by this stage.

The [independent input audit](input-review/independent-input-audit.json) verifies 117 bindings and all 229 members of the seven original archives. The prepared package contains all six ELF identities, original output oracles, upstream source bytes and exact reused candidate pools. Its integrity is bound by [preparation.json](preparation.json); [plan.json](plan.json) and [tools.json](tools.json) fix the execution contract.

The original equal-all-program error endpoint remains undefined because recursion yielded no eligible formulas. [Amendment V11b-E1](../../docs/v11b-transfer-protocol.md), explicitly [adopted before new predictions or labels](endpoint-adoption.json), keeps all six coverage outcomes visible and defines a separate equal-five-family/equal-eligible-program MAE comparison. It requires complete input outcomes and at least one nonempty program in every family. Empty recursion is never assigned zero error. The frozen V9 and V6 predictors remain unchanged.

The new runner streams raw Spike commits directly to native gzip, then separately supervises decoding and unchanged full-ROI extraction/fusion checks. Capture is limited to 300 seconds per program, decode to 1,800 seconds and extraction to 300 seconds. Storage, process cleanup and failure retention are enforced; compressed trace payloads are not duplicated in the metadata archive. A separate audited release is required before features, predictions or target measurements.

The recovery and scoring implementation has [124 focused tests and 30 subtests](input-review/focused-tests.log), including synthetic process failures and complete-package replay. These checks establish implementation behavior, not new program-transfer accuracy. Actual execution, if released, is recorded in the separate approval, claim and completion receipts; this preparation does not establish recovered traces or model improvement.
