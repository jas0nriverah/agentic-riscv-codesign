## Transport and validation

The NEW [capture_v11_spooled.py](../scripts/capture_v11_spooled.py) is an engineering helper, **not a released cohort collector**. It has no workload capture CLI. `capture_raw` starts the pinned gzip executable with `-1 -n -c`, then the same Spike argument array (`--isa=rv32im_zicntr -m16 --log-commits --log=/dev/fd/N original.elf`). Only the commit FD is inherited; HTIF stdout, Spike stderr and compressor stderr remain separate. Close parent pipe ends immediately. Python only polls process/resource state; it does not parse or filter commits during capture. Existing normalized JSONL is not an authentic raw Spike log and cannot supply the missing raw capture. Both processes get owned sessions. Cleanup sends SIGKILL to every owned group even if its leader has already exited, then bounds leader reaping and group-disappearance checks within five seconds per group; missing groups are expected, while permission/reap/probe errors remain separate from the primary failure. Success requires both exit0, no remaining owned group and no cleanup failure. Record commands, environment, binary hashes, return codes and partial/final byte hashes. This produces **captured-not-validated** evidence only.

`decode_raw` stream-decompresses the entire raw gzip through the unchanged [parse_trace](../src/tracing.py) and [CountedTrace](../src/run_holdout_benchmarks.py#L62). It preserves global raw-line `seq`, all PC counts, discontinuity starts and `finish()`'s final boundary. It rejects missing/extra markers, missing register values, wrong modulo32 delta, unknown measured instructions, malformed `core` lines even after stop, invalid UTF8, truncated gzip and bad CRC/EOF. Never stop reading at the second marker. The synchronous helper must be placed in the separately owned/monitored1,800-second child by the future release adapter; its direct function call does not enforce that deadline itself.

After full decode, compare the single HTIF output/status to the exact retained O2/O0 snapshot and rerun the unchanged program-specific `validate_output` oracle over the pinned source. Authenticate unchanged ELF before/after. Use unchanged `readProgram`, static symbol boundaries, `extractCandidates(program,runs,starts,maxSize=4,limit=None)` and the existing fusion checker; all called soft-float/conversion/division helpers remain. Admit no partial or opaque-skipped pool. The emitted candidates and all occurrence metadata must pass a separate read-only package audit before features/predictions or labels are authorized.
