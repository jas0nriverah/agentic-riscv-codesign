# Matched MasterRTL SOG adaptation protocol

This experiment retrains the public MasterRTL area recipe on the same 713 unique isolated RV32 formulas and the same iCE40 SB_LUT4 labels as the five existing comparison artifacts. It compares prediction methods on one target. It does not reproduce MasterRTL's published ASIC-area scores, training corpus, standard-cell library, or complete sequential RTL scope.

The read-only reference is [hkust-zhiyao/MasterRTL](https://github.com/hkust-zhiyao/MasterRTL/tree/5bccf38f8db7bb511a793a709863e7cb1b333ab5), commit `5bccf38f8db7bb511a793a709863e7cb1b333ab5`. The artifact records SHA256 hashes of `ML_model/train/train.py`, its preprocessing file, `vlg2ir/graph_stat.py`, `feature_extract/area/feature_extra_graph_stat.py`, `ys_script/run_TinyRocket_sog.ys`, and `std_PPA.json`. No reference pickle is loaded or executed.

The fixed estimator follows the [public training function](https://github.com/hkust-zhiyao/MasterRTL/blob/5bccf38f8db7bb511a793a709863e7cb1b333ab5/ML_model/train/train.py): 25 XGBoost estimators, maximum depth 12, raw target. Worker threads change from 20 to 1 and the seed is fixed to 20261013 for reproducibility. Other estimator defaults remain those of the installed XGBoost library; its version and all fitted parameters are recorded. The public repository does not pin the original library defaults. Predictions are clipped at zero to respect the nonnegative LUT target. There is no hyperparameter search, model selection, or post-probe adjustment.

Each formula is converted by the same `generate_rtl` used for the measured candidate labels. The [reference pre-ABC flow](https://github.com/hkust-zhiyao/MasterRTL/blob/5bccf38f8db7bb511a793a709863e7cb1b333ab5/ys_script/run_TinyRocket_sog.ys) is adapted to its `candidate` top module:

```
hierarchy -check -top candidate
proc; flatten; opt; fsm; opt; memory; opt; techmap; opt
```

Yosys writes both the resulting SOG Verilog and JSON. There is no ABC, `synth_ice40`, placement, routing, or LUT target mapping in feature extraction. Native generated Verilog replaces the reference Verific source importer because these formulas require no additional HDL frontend.

The 14 features follow [cal_oper](https://github.com/hkust-zhiyao/MasterRTL/blob/5bccf38f8db7bb511a793a709863e7cb1b333ab5/vlg2ir/graph_stat.py): DFF bits, register fanout, IO bits, AND/OR/NOT/XOR/MUX operator counts, rounded sequential/combinational/total analytical area, and rounded static/dynamic/total analytical power. The exact relevant weights are copied from the reference `std_PPA.json`. Direct traversal of the Yosys JSON primitive graph replaces the reference Pyverilog AST-to-graph parser: every supported primitive has one output bit, so its count equals the bit-width weight used by `cal_oper`. Unexpected cell types or nonsingle-bit cells cause failure. Alias, concat, and repeat graph nodes have zero analytical weights in the reference and do not contribute to these operator counts. All 96 declared IO bits are counted, including unused ports; the reference graph traversal can omit disconnected declarations. This constant feature does not distinguish the fixed-port formulas. DFF, register-fanout, and sequential-area features are zero because these candidates are combinational.

The original, transfer, and final benchmark datasets provide 1098 program/formula occurrences across 17 nonempty programs, with 713 unique labeled formulas. All these labels have already been inspected and are development data. A fixed leave-one-program-out evaluation excludes every test formula from all training programs; each unique training formula receives one weight. It reports all fold predictions, pooled and macro-program MAE/RMSLE, positive-label MAPE, Pearson/Spearman, and explicit true-zero errors. MAPE never includes zero labels and is not converted to an accuracy percentage.

Before fitting, the configuration, source hashes, reference file hashes, training-data hash, and this document's hash are recorded. The 192 independent stress-probe **input formulas only** may be preprocessed before freezing. Probe measured labels, verification results, and synthesis results remain unread until the weights, schema, runtime sources, and preregistration are saved. All six frozen matched-target predictors will then be scored on the same verified probe labels, with family and overlap/novelty results retained. The primary endpoint is macro-family MAE; log and relative errors are secondary endpoints. No model substitution, refit, or grid change follows probe scoring.

Full candidate RTL, Yosys scripts, logs, SOG Verilog, JSON graphs, and feature manifests are cached under keys that include canonical formula, pipeline, source hashes, tool version/binary hash, feature schema, and weights. Inference reads only formulas and requires Yosys preprocessing on a cache miss. Initial extraction and cached feature-plus-ML latency are recorded separately. Cached or ML-only time cannot represent cold end-to-end latency. On cache reads, retained RTL, script, graph, SOG Verilog, and log hashes are checked and the 14 features are rederived from the retained JSON primitive graph. The local model artifact checks its own hash, configuration, and runtime sources. Its loader resolves the cache relative to the artifact directory rather than the original machine path. A copied complete cache can supply warm inference without running Yosys; cold extraction requires the frozen Yosys version and executable hash. The model therefore requires its feature cache and runtime sources for cached inference, or its compatible external Yosys tool for uncached formulas.
